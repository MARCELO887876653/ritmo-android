# Ritmo 1.0.3 • build 4

Versão para testar o sistema de atualização. Somente versionName e versionCode do aplicativo foram alterados em relação à 1.0.2. Não há mudanças de funcionalidades, banco, permissões ou dependências.

A atualização é opcional, com a mesma assinatura e applicationId `com.ritmo.treinos`. Instale por cima da versão anterior; não desinstale.

Para testar o download interno, mantenha a versão 1.0.2 instalada, publique esta release e abra Configurações → Verificar agora. Baixe pelo Ritmo e confirme a instalação no Android. Depois confira Versão 1.0.3 / Build 4 nas Configurações.
